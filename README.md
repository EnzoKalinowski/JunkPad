# 🌱 JunkPad
**DIY Macro Pad from Recycled Components – Modular, Customizable, No 3D Printing Required!**
🔧 *Build your own macro pad using salvaged electronics, Arduino, and a bit of tinkering.*

## 📌 About
**JunkPad** is an **open-source** project that lets you build your own **custom macro pad** (like a Stream Deck) using:
✅ **Recycled components** (buttons, potentiometers, enclosures, etc.).
✅ **Arduino Nano** (or ESP8266 for a wireless version).
✅ **Python script** to trigger macros on your PC.
✅ **Modular design** to adapt the project to your needs.

### Why JunkPad?
- **Eco-friendly**: Repurpose unused electronics.
- **Customizable**: Adjust the number of buttons, macros, and design.
- **Beginner to expert**: Guides for all skill levels.
- **Community-driven**: Share your builds and inspire others!
